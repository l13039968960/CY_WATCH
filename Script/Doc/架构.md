## 1. 系统最底层

这一层**与芯片强相关**——换芯片即换此层——自下而上分为 **Driver 层**与 **Core 层**。

### 1.1 Driver 层

芯片厂商提供的库文件。例如：内核厂商提供的 CMSIS 文件、芯片厂商提供的 HAL 库文件。

### 1.2 Core 层

Driver 层之上，包含 `main` 文件、系统文件与外设文件；这些文件**通过调用 Driver 层的文件来编写**。
